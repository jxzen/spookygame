# House rules as patterns

Each entry: name, problem, rule, reason, good example, bad example. The director's words are quoted verbatim.

## H1. Tone before build
- Problem: tone drifts when the director first sees it in a finished piece.
- Rule: before any first-of-kind build, ask the director clarifying questions about tone and show real media. Keep asking until the reference is picked.
- Reason: director, Q7: "ask for more input or clarifying questions earlier during the design of the game to get the tone right."
- Good: three reference readings shown before a single asset exists.
- Bad: a finished level that is the director's first look at the mood.

## H2. Fifteen-minute batches
- Problem: review fatigue makes verdicts sloppy.
- Rule: a review batch takes the director at most 15 minutes. Split anything larger.
- Reason: director, Q7: "a batch can take 15 minutes."
- Good: five three-ups on one page, one keystroke per pick.
- Bad: forty items on one page.

## H3. Epic openings
- Problem: none yet; this is a target.
- Rule: openings (of the game, and of missions if the core loop has them) are judged two-up against the director's picked title-sequence anchor.
- Reason: director, Q9: "make the game feel epic like a james bond intro".
- Good: to be set by the title-sequence pick.
- Bad: to be set by the first rejection.
