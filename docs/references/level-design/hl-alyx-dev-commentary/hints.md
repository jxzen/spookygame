# Hints (one mechanism per line)

- Make the goal the landmark: put the destination where it is visible from the start and compose the first view toward it (fog layers in between, a light beside it).
- Run leading lines (cables, rails, gutters) from where the player stands to the goal's vanishing point.
- Spread information in space: one important thing per area, not all at once.
- Put one lit fixture over the exit the player should take; leave the rest of the room darker.
- End a dark channel in light: the brightest region of the frame is the way on.
- Frame the next space through a dark doorway or arch.
- Keep side distractions short so attention drifts back to the path.
- When the world state changes, add a cue (music, sound) so the player remembers to move on.

## What not to copy
- City 17, the Citadel, Combine cables as such, headcrabs, the Strider, Russell, VR hand interaction.
- The warm brown/teal grade; our palette is black, white, grey, red (H5).
- Dialogue that names the target ("look out the window"): Valve call it heavy-handed; last resort only.
