# Hitotsume-kozo · build hints

- **Use it as a light lure:** a small warm light at the end of the street, the only light in the town. Our palette allows red for "the way forward". A red child's lantern leading the player would be a strong and dangerous double meaning. Decision for the director.
- It overlaps with the zashiki-warashi (two child silhouettes). Use one, not both, in a 5-10 minute mission.
