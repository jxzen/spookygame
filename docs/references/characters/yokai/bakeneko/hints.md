# Bakeneko · build hints

- **The best "maybe nothing" beat.** A real cat is a plausible inhabitant of a dead town, so this works as a low-stakes first glimpse if the akaname is cut.
- **Silhouette against the sky:** on a rooftop ridge, back-lit by the overcast glow. In greyscale, a two-legged cat shape is instantly readable at 0.5 s.
- Needs a quadruped rig plus an upright pose. A stock cat rig with one extra pose would do.
