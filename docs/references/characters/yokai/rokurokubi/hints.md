# Rokurokubi · build hints

- **Spline neck:** a tube mesh along a spline with the head at its tip. Animate the spline length, not bones. Withdrawal is a length tween with ease-in.
- **"Look up" trigger:** first-person players rarely look up. That is why this is an alternate: it rewards careful players but many will miss it. Use it as an optional beat.
- **Swap option:** if the chochin-obake is cut, the rokurokubi takes slot 4.
