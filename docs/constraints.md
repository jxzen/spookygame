# Constraints (DRAFT v0.2, 2026-11-12)

Every borrowed mechanism passes through this sheet before we build our version. "Undecided" items are open decisions for the director.

| Constraint | Value | Source |
|---|---|---|
| Camera | First person | Director, Q3 |
| Players | Single player | Director, Q1 |
| Scope | The first mission only, playable in 5–10 minutes | Director, t2: "Focus on only making the first mission fit into a 5-10 minute gameplay chunk" |
| Jam theme | "Director's cut". Make it extra epic | Director, t6 |
| Art style | Painted backgrounds, flat animated characters, Spirited Away palette. Painted medium over digital art. No film asset or character enters the build | Director, batch-1 pick (Spirited Away) and Q3 |
| Animation | Hand-drawn-film motion, studied from Spirited Away | Director, Q3 |
| Music | Ominous epic orchestral base (anchor: "Paul's Dream"), plus solo instruments from the region of each mission | Director, batch-1 pick and reason |
| Title sequence | Clean imagery centred on the main character; a warm-up into the mission (anchor: Skyfall main titles; second reading to study: Archer season 1 intro) | Director, batch-1 pick |
| Tone | Spy action with horror interludes | Director, t4 |
| Dimension shift | Rare: a big moment, "like a dimension shift in inception" | Director, t3 |
| Input | Mouse and keyboard, and controller | Director, t1: "kbm support or controller." |
| Platform | PC (inference from input and engine; confirm) | — |
| Engine | Unreal Engine is the end goal. The prototype stack is **undecided** | Director, t6: "unreal engine is the end goal but build it for prototytping for now." |
| Palette | Spirited Away palette; to be measured in Phase 2. One scheme per dimension is expected | Director, batch-1 pick |

## Homage limits (summary; detail in homage.md)

- Spy-film and caped-hero nods are motif only: no names, logos, emblems, likenesses or signature silhouettes.
- Films, games, novels and TV on the reference list are studied, never shipped from.
